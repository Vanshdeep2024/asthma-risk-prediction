# Asthma Risk Prediction

An AI/ML-based system that predicts the risk of asthma using patient-related health and lifestyle features.

## 📌 Project Overview

This project uses Machine Learning techniques to analyze input health-related data and predict whether a person may be at risk of asthma.

The project includes data preprocessing, feature handling, model training, evaluation, and prediction.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## ✨ Features

- Data preprocessing and cleaning
- Exploratory data analysis
- Machine Learning model training
- Model evaluation
- Asthma risk prediction
- Prediction based on user-provided features
